# Aula de Operadores em Python

Este projeto reúne exemplos dos principais operadores usados em Python.

## Conceitos da aula

- Operadores aritméticos
  - `+`, `-`, `*`, `/`, `//`, `%`, `**`
  - Usados para realizar cálculos matemáticos.

- Operadores de atribuição
  - `=`, `+=`, `-=`, `*=`, `/=`, `//=`, `%=` e `**=`
  - Permitem guardar valores e atualizar variáveis.

- Operadores de comparação
  - `==`, `!=`, `>`, `>=`, `<`, `<=`
  - Comparam valores e retornam `True` ou `False`.

- Operadores lógicos
  - `and`, `or`, `not`
  - Combinam condições para tomada de decisões.

- Operadores de associação
  - `in` e `not in`
  - Verificam se um valor está presente em uma sequência, como lista ou string.

- Operadores de identidade
  - `is` e `is not`
  - Comparam se duas variáveis apontam para o mesmo objeto na memória.

## Arquivos da aula

- `operadores_aritimeticos.py`
- `operadores_atribuicao.py`
- `operadores_comparacao.py`
- `operadores_logicos.py`
- `operadores_associacao.py`
- `operadores_identidade.py`

## Objetivo

Entender como usar operadores para:
- calcular valores,
- comparar resultados,
- validar condições,
- verificar pertencimento e identidade de objetos.
